# Mochi ドキュメント

**Mochi** は、Codex CLI / Claude Code / OpenCode のセッションを
**リポジトリ単位で集約・閲覧・検索・実行**する、Windows / macOS 向けデスクトップアプリケーションです。

## ドキュメント一覧

| ドキュメント | 内容 |
| --- | --- |
| [requirements.md](./requirements.md) | **要件定義書** — 背景・スコープ・機能要件（FR）・非機能要件（NFR）・データモデル・リスク・MVP 完了条件・決定事項 |
| [ui-spec.md](./ui-spec.md) | **UI 詳細仕様** — モック修正指示（M-1〜M-5）と未作成 9 画面の仕様（文言・状態遷移レベル） |
| [tool-integration.md](./tool-integration.md) | **ツール連携仕様（付録）** — 3 ツールのセッション保存場所・形式・再開コマンドの調査結果 |
| [Mochi-UI-mocks.html](./Mochi-UI-mocks.html) | **UI モック** — 32 画面。ブラウザで開く。変更履歴は [CHANGELOG-ui.md](./CHANGELOG-ui.md) |

## 決定事項（2026-09-10）

| 論点 | 決定 |
| --- | --- |
| レイアウト | **`1b`「Transcript first」** を採用（`1a` 3 ペイン固定案は不採用） |
| UI 表示言語 | **英語のみ**、多言語化は行わない ※日本語パス・日本語セッション本文の取り扱いは引き続き要件（NFR-6.4 / NFR-6.5） |
| 内蔵ターミナル（Q-1） | **MVP に含める** — 技術選定は Tauri 2 を維持しつつ M0 でスパイク必須（R-10） |
| 削除機能（Q-2） | **提供する** — 既定無効＋対象列挙＋ゴミ箱移動＋実行中は不可 |
| 複数マシン同期（Q-3） | **不要** |
| 対象ツール（Q-4） | **3 ツール固定** — アダプタ分離は内部設計にとどめ、プラグイン API は公開しない |
| 公開形態（Q-5） | **OSS** — ライセンス検査とゴールデンファイルの秘匿情報チェックを CI 必須に |
| Linux（Q-6） | 需要次第。**排除はしない**（v1 は非対象） |
| 単価テーブル（Q-7） | **ユーザー編集可能な外部設定**。未知モデルはコストを推定しない |
| ライセンス（Q-8） | **Apache License 2.0**（単独）。CLA は求めない。依存はコピーレフト系を CI で拒否 |
| 内蔵ターミナルの範囲（Q-9） | **対象 CLI の起動専用**。汎用シェルにはしない（ただし隔離ではない） |
| 終了時の挙動（Q-10） | **確認して終了する** |
